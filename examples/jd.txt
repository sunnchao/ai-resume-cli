# 全栈开发工程师

## 岗位职责

1. 熟练使用 Node.js/React 进行前端开发工作；
2. 使用 Python、Golang 等至少一门后端语言进行系统开发；
3. 参与系统架构设计和核心模块开发，负责前后端联调和优化；
4. 与产品、测试团队协作，确保项目按时高质量交付；
5. 有专有云项目经验者优先考虑。

## 任职要求
1. 计算机相关专业本科及以上学历；
2. 至少 3 年全栈开发经验；
3. 熟练掌握前端技术栈，包括 Node.js 和 React；
4. 熟悉后端开发，至少掌握 Python 或 Golang 语言；
5. 优先考虑有专有云相关项目经验的候选人；
6. 工作地点优先杭州/远程。
